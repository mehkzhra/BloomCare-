BLOOMCARE — HEALTH RECORD TEST SAMPLES
Synthetic demonstration records — not real patient reports or medical advice.

HOW TO USE
1. Sign in as a demo patient and open Add health observations.
2. Select glucose unit mg/dL and temperature unit °F.
3. Enter one record below, then select Run complete assessment.
4. Repeat with a new health record for each risk category.
5. Leave optional clinical/PE indicators empty for these maternal-risk tests.

These are manual-entry samples, not a supported file-import format.
Uploading this text under Reports will not automatically run an assessment.

Expected results were verified using the local cloud-build maternal_rf_v0.2 model.
The deployed model itself was not queried; a different model version may give different results.
Pregnancy duration is set to 28 weeks for the demo; it is not a maternal classifier input.
PE screening requires separate additional measurements; an incomplete PE result is expected here.
